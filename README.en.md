JGAgent is an AI coding workbench built by JieGuan, providing a desktop app, a browser interface, and a terminal Agent. This repository contains the clients, backend services, shared UI, and the Agent CLI with its runtime sources.

> This project is a secondary development based on the open-source [ZCode](https://github.com/zai-org/ZCode) (Apache-2.0). Thanks to the upstream community.

| Entry                | Purpose                                                          | Command                             |
| -------------------- | ---------------------------------------------------------------- | ----------------------------------- |
| Desktop              | Electron desktop app                                             | `pnpm dev:desktop`                  |
| Web / JGAgent CLI    | Terminal and browser workbench; bundles TUI, Web, backend, Agent  | `pnpm dev:web`                      |
| Agent CLI            | Use `zcode` in the terminal; also the Agent runtime for Desktop/Web | `pnpm --filter @zcode/cli dev`   |

## Setup

Prepare Git, Node.js **24.14.0** and pnpm **10.33.2** (see [mise.toml](mise.toml)). All dev and packaging commands below run from the repository root.

```bash
pnpm bootstrap
```

`pnpm bootstrap` installs workspace dependencies, prepares local desktop runtime resources, then runs `build:bootstrap`.

The Agent CLI and runtime sources live in [apps/zcode-cli/](apps/zcode-cli/) as a regular directory; no Git submodule is required.

| Command                         | Purpose                                                                 |
| ------------------------------- | ----------------------------------------------------------------------- |
| `pnpm install`                  | Install dependencies                                                    |
| `pnpm prepare:desktop-runtime`  | Prepare desktop runtime resources (includes remote assets by default)   |
| `pnpm prepare:remote-assets`    | Prepare remote runtime assets only                                      |
| `pnpm bootstrap:with-remote`    | Init dependencies, local and remote assets, then build (skips desktop bundle) |
| `pnpm build`                    | Run build scripts recursively across workspace packages                 |

## Development

### Desktop

```bash
pnpm dev:desktop

# Test environment
pnpm dev:desktop:test
```

Use `ZCODE_DATA_BASE_DIR` for an isolated data directory, e.g. on macOS / Linux:

```bash
ZCODE_DATA_BASE_DIR="$HOME/.jgagent-dev-home" pnpm dev:desktop:test
```

### Remote features (SSH/WSL)

Run `pnpm bootstrap:with-remote` first to prepare remote assets (mock-cdn), then `pnpm dev:desktop`. When connecting to a remote workspace, choose "upload after local download" for resources. Development assets come from local `packages/desktop/mock-cdn` and local build outputs, uploaded via SFTP; no CDN access.

### Web

```bash
pnpm dev:web

# Specify the backend workspace (macOS / Linux)
ZCODE_SERVER_WORKSPACE=/path/to/project pnpm dev:web
```

This starts the Web dev server (default `http://localhost:5173`) and the backend (default `http://localhost:3030`); open the former in a browser. `/ws` and general `/api` requests are proxied to the local backend; `/api/v1/oauth/token` is proxied to the configured product service.

After changing Agent sources, run `pnpm --filter @zcode/cli... build` and restart the server.

### JGAgent CLI distribution

The CLI distribution bundles TUI, Web, and Agent behind a single `zcode` command: no arguments opens the TUI; `--web` starts the Web UI; other arguments are passed to the Agent CLI. Both modes run locally without Electron.

```bash
zcode
zcode --web
zcode --web --workspace /path/to/project --port 3030 --no-open
zcode --help
zcode --web --help
```

Web mode uses the current directory as workspace, listens on `127.0.0.1`, picks a free port and opens the browser. Use `--host 0.0.0.0` for LAN access; a token is generated by default when listening on non-loopback addresses.

### CLI source development

```bash
pnpm --filter @zcode/cli dev --help
pnpm --filter @zcode/cli dev
pnpm --filter @zcode/cli... build
node apps/zcode-cli/packages/cli/dist/zcode.cjs --help
```

## Configuration

See [.env.example](.env.example) for service endpoints and build configuration; copy to `.env` for local overrides (`.env.local` for private overrides). Built-in defaults shipped with the client are documented in [config/README.md](config/README.md).

| Variable                             | Purpose                                                  |
| ------------------------------------ | -------------------------------------------------------- |
| `ZCODE_DATA_BASE_DIR`                | Base data directory (data goes under `.zcode/`)          |
| `ZCODE_SERVER_WORKSPACE`             | Workspace path for the Web backend                       |
| `ZCODE_BUILTIN_PROVIDER_CONFIG_FILE` | Local provider config file; built-in config if unset     |
| `ZCODE_DIST_BASE_URL`                | Download root used by the CLI install script             |

## Packaging

Third-party notice generation and distribution checks are described in [third-party/README.md](third-party/README.md).

### Desktop

```bash
pnpm bundle:desktop
pnpm bundle:desktop -- --os win --arch x64
```

Default target is macOS arm64; output goes to `packages/desktop/dist/`. `--os` supports `mac`, `win`, `linux`; `--arch` supports `x64`, `arm64`. Actual packaging and signing require platform-specific tooling.

### JGAgent CLI package

```bash
pnpm build:zcode --base-url https://downloads.example.com/jgagent/
```

`ZCODE_DIST_BASE_URL` must be set (env, `.env`, or `--base-url`). Output lands in `dist/zcode/`: the runtime package, sha256 digest, `latest.json` index, and `install.sh`. The directory can be uploaded to your download root.
