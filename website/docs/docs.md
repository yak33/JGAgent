# 产品文档

捷关 Agent（JGAgent）是捷关团队自研的 AI 工作台：**编程模式**面向开发者深入终端、Git 与代码变更，**办公模式**帮办公人群处理摘要与日常事务。本文档帮助你完成安装、配置与日常使用。

## 安装

1. 从[首页](/)下载 Windows 安装包（`JGAgent-latest-win-x64.exe`，始终是最新版本）。
2. 双击运行。安装包暂未签名：Windows 弹出 SmartScreen 时，点「更多信息」→「仍要运行」。
3. 安装完成后首次启动，进入引导页。

## 首次配置

1. 引导页选择「捷关模型网关」。
2. 粘贴你的 API Key（由团队管理员分配），点「继续」。
3. 模型清单会自动从捷关网关同步（GLM 与 Claude 系列共 14 个模型），无需手动维护。

数据全部保存在本机 `~/.jgagent/`，不依赖账号体系。

## 双模式

| 模式 | 面向 | 特点 |
| --- | --- | --- |
| 编程模式 | 开发者 | 完整呈现命令、输出与代码变更；内置终端、Git 面板、文件树 |
| 办公模式 | 办公人群 | 只看摘要与结果；主动任务推荐（整理文件、汇总周报等） |

切换方式：设置 → 外观 → 界面模式，随时切换。

## 模型与网关

- 模型清单从捷关模型网关实时拉取，网关新增模型后无需手动维护。
- 设置 → 模型设置 → 捷关模型网关 →「从端点获取模型」，可手动刷新模型列表。
- 如需更换 API Key 或 Base URL，在同一页面编辑后自动保存。

## 自动更新

v0.3.2 起支持应用内自动更新：新版本发布后，应用会提示更新并差分下载（只拉取变化部分）。更新前请保存进行中的任务。

## 常见问题

**Q：安装时 Windows 提示"已保护你的电脑"？**
安装包暂未签名。点「更多信息」→「仍要运行」即可，仅首次出现。

**Q：启动时提示选择模型 / 无可用模型？**
进入设置 → 模型设置，确认捷关模型网关已启用、API Key 已填写，点「从端点获取模型」同步。

**Q：如何反馈问题或提需求？**
使用右上角 ? 菜单中的「问题上报」「给产品提需求」，反馈会保存在本机并随版本接入统一收集。

**Q：数据存放在哪里？**
本机用户目录 `~/.jgagent/`（任务、配置、反馈），卸载应用删除该目录即可完全清理。
