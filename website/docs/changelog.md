# 更新日志

## v1.0.1 <Badge type="tip">正式版</Badge>

2026-11-24 · [下载 Windows 版](/downloads/JGHarness-1.0.1-win-x64.exe)

- 修复进入主界面一段时间后界面卡死、无响应（v1.0.0 最多见的问题）：服务代理对象被日志与诊断序列化时，每次都会发起一次跨进程调用（实测约 190 次/秒），叠加空时间线的高频布局副作用后拖垮渲染进程；本版从框架层消除该风暴，长时间挂机不再卡死
- 修复从 v0.x 升级安装 v1.0.0 后旧数据未迁移（被要求重新配置 API Key）：存储根迁移此前会被崩溃采集模块抢先创建的空目录挡住，本版将迁移提前到主进程最先执行；已被 v1.0.0 生成空配置覆盖的用户，安装本版并重启会自动用旧数据补齐（旧目录保留备份）
- 修复未配置模型时欢迎 / API Key 卡片贴在窗口左上角，恢复居中
- 文案修正：移除「请开通编程套餐」「连接账号」等不适用措辞（中 / 英 / 日 / 韩 / 俄同步）

## v1.0.0 <Badge type="tip">正式版</Badge>

2026-11-24 · [下载 Windows 版](/downloads/JGHarness-1.0.0-win-x64.exe)

- 首个正式版：同步上游 ZCode v4.0.0，官网与应用内不再标注 Preview
- 修复应用内自动更新：此前几个版本的更新检查实际没有生效，本版起恢复，更新包来自 GitHub Releases；升级到本版需要手动安装一次
- 品牌更名为「捷关Harness」（自 v0.7.0 起）：产品名、安装包名与数据目录同步更新，旧版数据首次启动时自动迁移
- 安全加固：应用主窗口拦截页面跳转，文档里的链接无法把应用窗口带到外部页面；打开可执行文件前先确认
- 诊断日志导出与反馈附件加固：CLI 配置只保留非敏感字段，超大日志保留完整尾部记录，Agent 崩溃证据按安全投影收录
- 凭据存储更稳：系统凭据库不可用（如 Windows 凭据管理器已满）时自动降级到本地私有密钥，密钥丢失后可自动恢复
- 稳定性：窗口渲染进程崩溃或出现错误页时可一键「重启应用」；有会话仍在运行时退出会先确认
- Agent 回复语言：设置 › 行为与工具 › 回复语言，可指定 Agent 用某种语言回复
- Skill 实时生效：新建、删除、启停 Skill 后下一次请求即生效，无需新开会话
- MCP：服务异步启动并提供等待就绪工具，需要重新授权时明确提示
- 插件商店：启停改为读写用户级配置，修复「关闭插件后新对话又被开启」
- 界面细节：中文旁的裸链接可点击、文件链接定位到行、@ 候选面板滚动位置、插件界面首帧主题、反馈窗口窄窗口布局
- 预装文档工具（LibreOffice / Python / Pandoc 等）暂未启用：上游实现依赖官方 CDN 下载，捷关版沿用「按需安装」流程
- Web 远控保持直连链路；反馈与账号体系保持捷关自建方案不变
